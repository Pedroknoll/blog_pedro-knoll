O blog é um site estático — o motivo está em [por que este blog existe](/blog/2026-10-por-que-este-blog/). O HTML sai pronto no build.

## Como a página é gerada

O Astro lê o Markdown e entrega o HTML.

### O processador

Um processador único trata Markdown e MDX.

## O que o leitor vê

Texto, data e um sumário com os títulos da página.

#### Detalhe que não entra no sumário

Esta linha fica de fora do sumário.

## O que o texto carrega

O processador `unified` trata o Markdown.

```ts title=dobro.ts
function dobro(n: number): number {
  return n * 2;
}
```

Para gerar o site, um comando basta:

```sh
pnpm build
```

A soma dos quadrados de $x_i$ é a norma ao quadrado:

$$
\sum_{i=1}^{n} x_i^2 = \lVert x \rVert^2
$$

<Callout variant="note">

Para ver o site como em produção, rode `pnpm build && npx wrangler dev`.

</Callout>

<Callout variant="caution">

Não edite `dist/_headers` à mão: o arquivo é gerado no build.

</Callout>
